BaidehiJha is a graphically affluent online store website providing handloomed ethnic wear, particularly Anarkali suits. The website displays a mix of age-old sophistication and contemporary looks, with pages such as new arrivals, product catalog, user reviews, and a blog known as "Royal Threads."

Pages Included:

index.html: Principal landing page with hero banner, products, about section, reviews, and footer.

blog.html: Exclusive blog page displaying fashion articles under "Royal Threads".

Features:

Elegant UI in soft beige, gold, and earthy tones

Responsive desktop and mobile layout

Interactive product cards with hover animation

Read More toggle for blog content

Fixed navigation bar with search, cart, and user dropdown

Review carousel with Swiper.js

Translucent "About" section with custom background image

Footer with functional navigation and social links

Technologies Used:

HTML5, CSS3, JavaScript

Google Fonts (Ancizar Serif)

Boxicons for icons

Swiper.js for sliders

Folder Structure:

/fonts: Custom font files

index.html: Home page

blog.html: Blog content

style.css: Custom styles

main.js: Script for interactivity
